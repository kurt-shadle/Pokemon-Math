# Pokemon Math

A browser math game for kids: solve equations using Pokémon National Dex numbers.

## Play online (phone or computer)

**https://kurt-shadle.github.io/Pokemon-Math/**

First-time setup: enable **Settings → Pages → Build and deployment → Source: GitHub Actions** on the [GitHub repo](https://github.com/kurt-shadle/Pokemon-Math), then push to `main` (or run the **Deploy GitHub Pages** workflow once).

## Car trip / offline

See **[pokemon-math/docs/OFFLINE.md](pokemon-math/docs/OFFLINE.md)** for the preload checklist (Android Chrome, airplane-mode test).

Summary: open the HTTPS link on the phone while on Wi‑Fi, let it fully load and cache images, add to Home screen, then test with airplane mode before you leave.
